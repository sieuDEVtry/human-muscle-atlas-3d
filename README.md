# Giải phẫu cơ người 3D

Website 3D tương tác cho phép xoay mô hình cơ thể người, nhận diện sáu vùng cơ chính và mở từng vùng trong chế độ xem chi tiết 360°.

## Các vùng tương tác

- Bụng
- Đùi
- Vai
- Bắp tay
- Ngực
- Mông

## Chạy trên máy

```bash
npm install
npm run dev
```

## Ghi công và giấy phép

Hình học giải phẫu được chuyển đổi và tối ưu từ:

- **BodyParts3D — The Database Center for Life Science — CC BY-SA 2.1 Japan**
- **Z-Anatomy — The libre 3D atlas of anatomy — CC BY-SA 4.0**
